## 1. 판정

`G4 Authenticated`의 로컬 구현 검증은 PASS다. 실제 기관 IdP onboarding과 원격 Host 2종 검증은 F4/G5에 남아 있으므로 Foundation 전체나 production-ready 판정은 아니다.

`VAL-OAUTH-009` inbound token의 downstream 부재는 Collector가 아직 없으므로 C0 gate로 유지한다. 현재 `AuthorizationContext`, DB, log에는 raw token을 전달하지 않는 것을 검증했다.

## 4. 실제 Migration 검증

PostgreSQL 17에서 다음을 실행했다.

```text
0001_foundation → upgrade head → 0002_external_identity
0002_external_identity → downgrade 0001_foundation
0001_foundation → upgrade head → 0002_external_identity
```

`external_identities`는 RLS enabled+forced이며 runtime pool이 tenant context 없이 조회하면 0건이다. `users` table 직접 조회는 privilege 단계에서 거부된다.

## 5. Security Review

초기 구현 검토에서 다음 두 P1 후보를 발견해 이 increment 안에서 닫았다.

1. HTTP response를 전부 받은 뒤 크기를 확인하던 OIDC loader를 bounded streaming으로 변경했다.
2. runtime의 `ALL TABLES` DML grant를 table별 최소권한으로 바꾸고 `users` 조회 거부를 test로 고정했다.

현재 범위의 미해결 P0/P1은 0건이다. 외부 security review와 기관 penetration test는 G6 이전에 별도로 수행한다.
