### VAL-REMOTE-002 — TLS terminating reverse proxy

```text
Command: pytest tests/integration/test_tls_reverse_proxy.py
Expected: generated CA verifies HTTPS proxy; proxy forwards to HTTP backend;
          full conformance and reconnect pass
Observed: PASS
Evidence: tests/integration/test_tls_reverse_proxy.py
```

Test는 runtime에 1-day CA와 localhost SAN certificate를 생성한다. client는 `ssl.create_default_context(cafile=...)`로 CA를 검증하고 HTTPS endpoint만 허용한다. plaintext endpoint에 `--ca-bundle`을 지정하면 fail closed한다.

### VAL-REMOTE-003 — HTTP resource controls

```text
Expected: 413 oversize, 504 bounded timeout, 429 Retry-After,
          token 비노출, validated X-Request-ID
Observed: PASS
Evidence: tests/unit/test_http_policy.py
```

Rate key는 raw bearer가 아니라 SHA-256 token digest와 source IP를 사용한다. 최대 10,000 key의 process-local LRU bound를 갖는다. 다중 replica global quota는 gateway 책임으로 문서화했다.

## 5. MCP Inspector 실제 Host 검증

Endpoint는 연속 실행 중인 development server `http://127.0.0.1:8765/mcp`였다. 각 CLI command는 독립 process다.

| Method | 관찰 |
|---|---|
| `tools/list` | 5개 canonical Tool과 schema/annotations |
| `tools/call psr.project.list` | Project, structuredContent, text, operation ID |
| `resources/templates/list` | 2개 canonical template |
| `resources/read` | Project JSON Resource |
| `prompts/list` | `public_policy_research` |
| `prompts/get` | 3개 argument를 반영한 user message |
| `run.start` | Run `0cd6eafa-4463-49ee-a156-1c8fffa79427`, `QUEUED` |
| 새 process `run.status` | 같은 Run ID와 상태 |
| 새 process Run Resource | 같은 Run ID의 JSON Resource |

Inspector Prompt argument 옵션은 `--prompt-args`다. 잘못된 `--prompt-arg` 시도는 URL argument로 해석돼 실패했으며, 공식 CLI 구현을 확인해 올바른 옵션으로 재실행 후 PASS했다.

## 6. Codex 실제 Host 검증

글로벌 wrapper는 native binary 누락으로 실패해 ChatGPT app bundle의 native Codex CLI를 사용했다. 설정은 `--ignore-user-config --ephemeral -s read-only`였고 repository나 사용자 config를 변경하지 않았다.

관찰된 JSONL event:

```text
event: mcp_tool_call
server: psr
tool: psr.project.list
result: structured + text Project page
agent output: project-public-ai
exit: 0
```

Resource/Prompt까지 호출하는 후속 Codex 실행은 approval reviewer가 “로컬 MCP resource/prompt content를 외부 service로 전송할 수 있다”는 이유로 거부했다. 정책 우회 없이 중단했다. 이 검증에는 사용자의 명시적 전송 승인이 필요하다.
