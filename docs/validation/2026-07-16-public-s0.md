## 4. 확인한 보안 동작

- 같은 IP가 invalid bearer를 바꿔도 quota를 새로 얻지 못한다.
- rate key에는 raw IP와 raw bearer가 들어가지 않는다.
- public Tool은 OAuth token 없이 호출된다.
- public catalog에는 Foundation Project/Run Tool이 없다.
- workspace path에 user input을 사용할 수 없다.
- symlink root, path traversal, unsafe file target을 거부한다.
- 만료·blocked workspace content는 읽거나 쓸 수 없다.
- corrupt lease의 오래된 orphan은 강제 삭제한다.
- sweeper 실패는 process를 종료시키지 않고 다음 실행을 허용한다.

## 5. PG0 잔여항목

S0 구현 완료가 PG0 전체 통과를 뜻하지 않는다.

- 실제 question/source/result canary를 사용하는 quick lifecycle
- kill switch가 quick/start를 거부하고 result/purge는 유지하는 test
- trusted edge의 client IP normalization과 spoof 방지
- raw content가 log/trace/crash output에 없다는 end-to-end scan
- 삭제 transient failure의 실제 retry/backoff와 alert

위 항목은 fake quick vertical slice와 함께 다음 change set에서 닫는다.
