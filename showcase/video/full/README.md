# 공공복리 60초 소개영상

인트로·아웃트로와 실제 HTML 보고서, 공식 출처 확인 장면을 합친 60초 소개영상입니다.

## 구성

- 0:00–0:06 `공·공·복·리` 첫 글자를 강조한 인트로
- 0:06–0:10 보고서 제목과 조사상태
- 0:10–0:34 보고서 근거에서 GOV.UK 공식 원문까지 직접 확인
- 0:34–0:42 핵심 확인사항과 업무 시사점
- 0:42–0:49 검토 권고와 리스크 점검
- 0:49–0:55 추가 확인사항과 적용 한계
- 0:55–1:00 아웃트로

## 제작

Chrome과 `ffmpeg`가 설치된 환경에서 영상 제작용 의존성을 설치합니다.

```bash
npm install --prefix showcase/video/full
```

그런 다음 저장소 루트에서 정적 서버를 실행하고, 별도 터미널에서 전체 빌드를 실행합니다.

```bash
python3 -m http.server 4173 --bind 127.0.0.1
node showcase/video/full/build_full.js
```

특정 장면만 다시 촬영하고 나머지 클립을 재사용할 수 있습니다.

```bash
node showcase/video/full/build_full.js --reuse --scenes=1,6
```

각 장면은 1920×1080, 30fps, H.264로 정규화하며 0.333초 크로스페이드로 연결합니다. `qa/`에는 장면별 3×3 프레임 점검표, `final/`에는 전체 영상과 4×3 프레임 점검표가 생성됩니다.

저장소에는 최종 60초 영상과 전체 흐름을 확인할 수 있는 콘택트시트만 포함합니다. 원본 녹화, 중간 클립, QA 렌더는 재생성 가능한 로컬 빌드 산출물로 취급합니다.
